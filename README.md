# Portfólio Boniek

Portfólio pessoal de **Boniek Junior**, desenvolvedor Fullstack com interesse em engenharia de software, inteligência artificial e criação de soluções para problemas reais.

**[Acessar o site](https://portfolio-boniek.vercel.app/pt)** · **[GitHub](https://github.com/boniek-junior)** · **[LinkedIn](https://www.linkedin.com/in/boniek-junior-561448281/)**

## Sobre o projeto

Uma experiência web interativa construída para apresentar minha trajetória acadêmica e profissional, projetos selecionados e a maneira como conecto desenvolvimento, IA e design.

### Tecnologias

- **Next.js 15** e **React 19**
- **TypeScript** e **Tailwind CSS 4**
- **next-intl** para versões em português e inglês
- **Motion** para transições e animações
- **hls.js** para reprodução de vídeo em streaming

## Executando localmente

Pré-requisitos: Node.js e um gerenciador de pacotes compatível.

```bash
git clone https://github.com/boniek-junior/portfolio-boniek.git
cd portfolio-boniek
npm install
npm run dev
```

Abra [http://localhost:3000/pt](http://localhost:3000/pt).

## Estrutura principal

- `app/[locale]/`: páginas localizadas
- `components/`: componentes visuais e animações
- `messages/`: traduções para português e inglês
- `public/`: arquivos estáticos e mídias locais

## Notas

Algumas animações utilizam mídias hospedadas externamente; sua reprodução depende de conexão com a internet e das políticas de reprodução automática do navegador. Em dispositivos móveis, o navegador pode limitar autoplay.
